01 / THE PROBLEM

Show the steps.

A result alone hides the work. The trace shows where input is checked, data is read and a response is shaped.

02 / THE APPROACH

Keep the logic separate.

The same request function drives both demos. Rendering and animation consume its result; they do not decide whether the request succeeds.

03 / THE TRADE-OFF

Load only what is needed.

Run the demo locally and load 3D only on request. That keeps it usable without a backend or a powerful graphics chip.
